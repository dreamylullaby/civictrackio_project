Referencia

Funciones y triggers

asignar_zona_y_comuna()
TRIGGER · BEFORE INSERT OR UPDATE
Asigna automáticamente zona_id y comuna a un reporte usando PostGIS. Primero cruza coordenadas con secciones_dane, luego busca por nombre exacto del barrio como fallback.
asignar_zona_automatica()
TRIGGER · BEFORE INSERT OR UPDATE · WHEN zona_id IS NULL
Fallback final: asigna zona por similitud usando Levenshtein sobre el nombre del barrio ingresado.
asignar_o_crear_incidente()
TRIGGER · AFTER INSERT
Agrupa reportes en incidentes si hay otro reporte del mismo tipo/fecha/franja en un radio de 150m. Si no existe, crea un incidente nuevo. Actualiza el centroide promediando coordenadas.
get_zona_por_coordenadas(lat, lng)
RPC · Función SQL
Dado un punto geográfico, retorna la comuna y el arreglo de barrios contenidos en esa sección censal DANE.
get_corregimiento_por_coordenadas(lat, lng)
RPC · Función SQL
Retorna el corregimiento y sus veredas para coordenadas en zona rural, usando ST_Contains con los polígonos cargados.
calcular_nivel_riesgo(cantidad)
Función IMMUTABLE
Retorna el nivel de riesgo según cantidad de reportes: ≤3 seguro · ≤7 medio · ≤10 alto · >10 peligroso. Usada en las vistas del dashboard.
eliminar_cuenta_usuario(p_usuario_id)
Función PL/pgSQL
Soft delete con anonimización: cambia estado a eliminado, sobrescribe username/correo, borra tokens y configuración de alertas. No elimina reportes asociados.
buscar_barrio_similar(texto)
RPC · Función SQL
Retorna los 5 barrios más parecidos al texto ingresado usando distancia Levenshtein + unaccent. Sirve para el autocompletado y el trigger de zona automática.
